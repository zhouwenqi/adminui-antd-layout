# antd-layout 是什么？
antd-layout `@adminui-dev/antd-layout` 是一款基于 [ant-design](https://ant.design/) 和 [react-router](https://reactrouter.com/) 打造的前端布局组件，它是完全开源的，拥有灵活且丰富的布局形态和样式，同时支持自定义皮肤主题样式，非常适合有个性需求的中后台和web仪表盘项目使用。以下简称 `antd-layout`：

🎉 [效果展示](https://demo.adminui.dev)

## 布局组件
前端框架中布局页面（组件）通常位于 `src/layouts` 目录下，`antd-layout` 以组件形式添加到布局文件中，通过相应的配置参数让整个项目的所有页面呈出丰富多彩的样式，灵活度极高。

### 组件特征
- 支持多种版式和细节属性控制
- 支持动态单色主题切换
- 支持自定义主题皮肤
- 支持i18n国际化
- 品牌大小和色深控制
- 用户形象位置细节控制
- 细致到基础控件的图标控制


## 技术栈
- node.js(22+)
- react(18+)
- react-intl(8.0)
- react-router(7.11)
- ant-design(6.10)
- vite(7.0+)

## 适用场景
- 单页面布局的后台管理系统
- 个性化UI的仪表盘项目
- saas管理系统
- 基于 [ant-design](https://ant.design/) 套件开发的系统

## 不适用的场景
- 需要服务端渲染的项目
- 需要全站静态化的项目
- 面向用户端自由布局平台
